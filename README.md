# Kartu Ucapan dengan Splash Screen & Animasi

Proyek web sederhana untuk menampilkan kartu ucapan digital dengan animasi kejutan. Aplikasi ini dimulai dengan sebuah *splash screen* (layar pembuka) yang mengarahkan pengguna ke kartu ucapan utama.

## ✨ Fitur

- **Splash Screen:** Layar pembuka yang menarik dengan pesan selamat datang sebelum menampilkan kartu utama.
- **Animasi Transisi:** Transisi *fade-out* dan *fade-in* yang mulus dari splash screen ke kartu ucapan.
- **Tombol Kejutan:** Sebuah tombol yang memicu berbagai animasi visual secara bersamaan:
  - Hujan konfeti (confetti).
  - Balon yang terbang ke atas.
  - Bunga yang bermunculan.
- **Desain Modern:** Tampilan yang bersih dan modern dengan gradien latar belakang.

## 🚀 Cara Menjalankan

1.  Clone atau unduh repositori ini.
2.  Susun file dan folder sesuai dengan struktur di bawah.
3.  Buka file `index.html` di browser web modern seperti Chrome, Firefox, atau Safari.

## 📂 Struktur Proyek

```
├── css/
│   └── style.css
├── js/
│   └── main.js
├── index.html
└── README.md
```
